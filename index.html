How This Academy Was Built

Curriculum lineage

The lesson sequence follows the celebrated Madinah Books method (Dr. V. Abdur Rahim, Islamic University of Madinah) for non-native speakers, combined with frequency-first vocabulary from the Quranic Arabic Corpus — so you learn the words that appear most in the Quran first. Tajweed modules follow the standard Hafs 'an 'Asim rules taught worldwide.

Data sources (free & open)

• Quran text: Tanzil Uthmani via fawazahmed0/quran-api
• Translation: Saheeh International
• Word-by-word + audio: quran.com API v4 / verses.quran.com
• Recitation: cdn.islamic.network (Mishary Alafasy)
• Pronunciation audio: Microsoft Edge neural TTS (ar-SA-Zariyah)
